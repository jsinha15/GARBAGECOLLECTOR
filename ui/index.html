Words used on this page

Root
A reference that lives outside the heap, here a variable in your code. The collector starts its search from the roots.
Reachable / garbage
Reachable = a chain of references leads to it from a root. Garbage = no chain exists, so the program can never use it again.
Mark
Colour reachable objects: white (not seen) → gray (found, waiting) → black (fully scanned) → live.
Sweep
Walk the heap and free every object that was not marked.
Compact / forwarding address
Slide live objects together. Each survivor first gets a forwarding address, then all references are rewritten, then objects move.
Copying (from-space / to-space)
Copy live objects into an empty space and throw the old space away. Survivors end up contiguous.
Eden, Survivor, Old
New objects start in Eden. Survivors of a minor GC age in the Survivor spaces and are promoted to Old when old enough.
Write barrier / remembered set / card table
Code run on every reference store that records old→young pointers, so a minor GC can treat them as extra roots.
Reference count
Number of references to an object. At 0 it is freed immediately; cycles never reach 0.
Safepoint / stop-the-world
Threads park at safe places so the collector can work while the program is paused.
Fragmentation
Free memory split into many small holes; allocation can fail even when enough total space is free.
